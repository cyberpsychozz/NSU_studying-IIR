# Лабораторная работа 1 — UpSet plot пропусков

Откройте `lab_01_upset.ipynb` в JupyterLab или VS Code и выполните ячейки сверху вниз. Ноутбук читает локальный архив `beijing_air_quality_uci.zip` и сохраняет график `upset_beijing.png`. Доступ к интернету при запуске не нужен.

При необходимости установите зависимости:

```bash
python3 -m pip install -r requirements.txt
jupyter lab
```

## Данные

[Beijing Multi-Site Air Quality](https://archive.ics.uci.edu/dataset/501/beijing%2Bmulti%2Bsite%2Bair%2B%20quality%2Bdata), UCI Machine Learning Repository, Song Chen (2017), DOI: 10.24432/C5RK5G, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Локальный архив содержит 12 исходных CSV по станциям Пекина: 420 768 часовых записей, 18 исходных столбцов. Пропущенные значения в исходных CSV обозначены `NA`.

`test.csv` от предыдущей версии лабораторной сохранён, но ноутбук его больше не читает.

## Что показывает диаграмма

- В 12 измеряемых полях есть пропуски; найдено 81 точное сочетание.
- Без пропусков — 382 168 записей, с пропусками — 38 600.
- На графике показаны 25 самых частых сочетаний. Они охватывают 38 083 записи, то есть 98,7% записей с пропусками.
- Верхние узкие цветные столбики показывают размеры сочетаний, матрица — отсутствующие поля, оранжевые столбики слева — число пропусков в каждом поле.
- Нижняя таблица показывает долю каждой станции и каждого сезона **внутри** соответствующего сочетания; оранжевые столбики слева от неё показывают размеры этих групп во всём наборе. Станции и сезоны не считаются пропусками.

Итоговые значения напечатаны в ячейках ноутбука. График также сохранён отдельным PNG для просмотра или вставки в отчёт.
